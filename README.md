# 📊 Sales Analysis & Customer Insights Dashboard

## 📌 Project Overview

This project focuses on analyzing customer purchasing behavior, sales performance, product trends, regional performance, and customer retention.

The project was completed as a **7-day data analytics journey**, starting from data loading and cleaning and ending with an interactive dashboard, business recommendations, and an executive summary.

The main goal is to convert raw sales data into meaningful business insights that can help improve sales performance, customer engagement, and business decision-making.

---

## 🎯 Project Objectives

* Analyze customer purchasing patterns
* Identify the most valuable customers
* Find the best-selling products
* Analyze sales trends over time
* Compare regional sales performance
* Calculate customer lifetime value and retention metrics
* Identify cross-selling opportunities
* Create meaningful data visualizations
* Build a sales performance dashboard
* Provide business recommendations based on data

---

# 🗓️ 7-Day Project Journey

## 🔹 Day 1: Data Loading and Exploration

### Tasks Completed

* Loaded the sales and customer datasets
* Explored the structure of the datasets
* Checked the number of rows and columns
* Examined data types
* Checked for missing values
* Reviewed basic statistical information
* Understood the important columns and business variables

### Goal

To understand the available data before starting the analysis.

---

## 🔹 Day 2: Data Cleaning and Preparation

### Tasks Completed

* Handled missing values
* Converted date columns into the correct date format
* Converted numerical columns into appropriate data types
* Checked for inconsistent or invalid values
* Created calculated columns where required
* Prepared the dataset for further analysis

### Goal

To create a clean and reliable dataset for analysis.

---

## 🔹 Day 3: Customer Analysis

### Tasks Completed

* Identified the most valuable customers
* Calculated customer sales contribution
* Analyzed customer purchasing behavior
* Calculated customer lifetime value where applicable
* Analyzed customer distribution by region
* Identified high-value customers for targeted marketing

### Key Business Question

**Who are our most valuable customers?**

The analysis helps identify customers who contribute the highest sales and can be targeted with loyalty programs, personalized offers, and retention campaigns.

---

## 🔹 Day 4: Sales Pattern Analysis

### Tasks Completed

* Grouped sales data by date/month
* Analyzed sales trends
* Identified the best-selling products
* Compared product performance
* Analyzed regional sales
* Studied changes in sales performance over time

### Key Business Questions

**Which product sells the best?**

**Which region generates the highest sales?**

These insights help businesses understand their strongest products and markets.

---

## 🔹 Day 5: Advanced Analysis

### Tasks Completed

* Created pivot tables
* Compared different customer and sales segments
* Calculated retention-related metrics
* Analyzed customer behavior
* Identified potential cross-selling opportunities
* Studied relationships between products and customer purchases

### Key Business Question

**What products can be promoted together?**

Cross-selling analysis can help businesses create product bundles and personalized recommendations.

> **Note:** Meaningful product co-purchase analysis requires multiple product transactions for the same customer. If each customer has only one product transaction, true product-pair analysis cannot be reliably calculated.

---

## 🔹 Day 6: Dashboard Creation

### Dashboard Features

The sales dashboard was created using multiple visualization types to make the analysis easier to understand.

### 📈 Visualizations

* **KPI Cards** – Total Sales, Transactions, Quantity Sold, Customers
* **Bar Chart** – Top Customers
* **Bar Chart** – Product Performance
* **Regional Sales Chart** – Sales comparison by region
* **Line Chart** – Sales trend over time
* **Pie/Distribution Chart** – Sales distribution
* **Tables** – Detailed customer and regional analysis

### Dashboard Purpose

The dashboard provides a simple view of important business metrics and allows users to quickly identify trends, opportunities, and areas that need improvement.

---

## 🔹 Day 7: Report and Business Insights

### Tasks Completed

* Created an executive summary
* Identified important business findings
* Developed customer retention recommendations
* Suggested strategies for increasing sales
* Identified opportunities for cross-selling
* Provided recommendations based on customer and regional performance

### 💡 Business Recommendations

#### 1. Focus on High-Value Customers

Provide loyalty rewards, personalized offers, and special promotions to customers generating high revenue.

#### 2. Improve Customer Retention

Monitor customer behavior and provide personalized communication to customers who may be at risk of leaving.

#### 3. Promote Best-Selling Products

Focus marketing campaigns on products that generate strong sales and use them to attract new customers.

#### 4. Improve Regional Performance

Invest more marketing resources in high-performing regions while identifying opportunities to improve weaker regions.

#### 5. Use Cross-Selling

Recommend related products to customers based on their purchasing history.

#### 6. Use Data for Personalized Marketing

Instead of sending the same promotion to every customer, use customer purchasing behavior to create targeted campaigns.

# 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Sales-Analysis-Dashboard.git
```

### 2. Open the project folder

```bash
cd Sales-Analysis-Dashboard
```

### 3. Install required libraries

```bash
pip install pandas numpy plotly streamlit
```

### 4. Run the Streamlit dashboard

```bash
streamlit run app.py
```

### 5. Open the dashboard

After running the command, Streamlit will provide a local URL where you can view the dashboard.
